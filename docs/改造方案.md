# FusionWeb 容器化与一键部署改造方案

## 一、目标架构

FusionWeb 生产环境采用六服务 Docker Compose 架构：

```text
浏览器
  │ HTTP 8756 / HTTPS 8988
  ▼
fusionweb-web (Nginx + 静态前端)
  │ /api /ws
  ▼
fusionweb-api
  ├── PostgreSQL
  ├── Redis Stream
  └── MinIO
       ▲
       │ 任务消费与结果写入
fusionweb-worker（默认本机 Worker，可扩展远程 Worker）
```

API 不执行本地扫描任务，`FUSIONWEB_LOCAL_CONSUMER=false`。默认 Worker 始终随主 Compose 启动并消费 Redis 队列。

## 二、部署原则

- 生产 Compose 仅使用镜像，不包含业务服务 `build:`；
- 六个镜像统一从阿里云 ACR 杭州区公开仓库拉取；
- API、Web、Worker 使用根目录 `VERSION` 固定版本；
- PostgreSQL、Redis、MinIO 使用固定上游版本同步到 ACR；
- Windows 使用 Docker Desktop Linux Containers；
- 所有发布镜像目标为 `linux/amd64`；
- `.env`、数据库密码、JWT、Basic Auth 密码和 Worker Key 不进入镜像；
- 部署服务器不编译 Worker 扫描工具。

## 三、运行配置

应用配置全部来自环境变量和 `.env`。主配置项见 `.env.example`：

- `FUSIONWEB_IMAGE_PREFIX`；
- `FUSIONWEB_VERSION`；
- Web 端口与 Basic Auth；
- PostgreSQL、Redis、MinIO 连接与凭据；
- JWT Secret；
- 默认 Worker 名称、并发数和 Worker Key；
- 远程 Worker 外部连接地址。

## 四、生产与开发分离

生产：

```bash
./fusionweb.sh install
```

开发：

```bash
docker compose -f docker-compose.yaml -f docker-compose.dev.yaml --env-file .env up -d --build
```

开发覆盖层只为 API、Web、Worker 添加源码构建定义，并映射 PostgreSQL、Redis、MinIO 端口。

## 五、镜像发布

GitHub Actions 从 `VERSION` 读取版本，构建 API、Web、Worker 的 `linux/amd64` 镜像，并同步固定版本 PostgreSQL、Redis、MinIO。业务镜像同时发布固定版本和 `latest`。`v*` Tag 必须与 `VERSION` 一致。

## 六、一键管理入口

Linux 唯一生产管理入口：

```text
fusionweb.sh
```

Windows 唯一生产管理入口：

```text
fusionweb.bat
```

统一命令：

```text
install upgrade check-update start stop restart status logs version uninstall help
```

## 七、远程 Worker

主 Compose 默认不开放基础设施端口。需要远程 Worker 时叠加 `docker-compose.remote-access.yaml`，配置远程可访问的 PostgreSQL、Redis、MinIO 地址，再由前端“节点管理”生成 Linux/Windows 一键部署命令。

远程 Worker 与默认 Worker 使用相同 ACR 镜像和版本。

## 八、数据与卸载

普通停止、重启、升级、固定版本回滚均保留数据卷。只有 `uninstall` 在用户输入 `DELETE` 明确确认后执行 `down -v --remove-orphans`。源码与 `.env` 始终保留。

## 九、验收标准

- 生产 Compose 与开发覆盖层配置解析通过；
- Linux 与 Windows 管理脚本的基础命令可执行；
- GitHub Actions YAML 可解析；
- Go 测试、前端类型检查和生产构建通过；
- 三个业务 Dockerfile 通过 BuildKit 静态检查；
- 六个 ACR 镜像可匿名拉取；
- 全新 Linux/Windows 主机只运行一个管理脚本即可启动；
- 默认 Worker 能消费扫描任务；
- 远程 Worker 命令使用相同 ACR 镜像；
- 回滚不删除数据，卸载确认后删除数据卷。
